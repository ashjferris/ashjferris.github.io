# Ash Ferris

The source for [ashjferris.github.io](https://ashjferris.github.io/), a personal site about applied AI, cognition, writing, and experiments.

## Local development

Start a local server:

```sh
npm run serve
```

Then open [http://localhost:8080](http://localhost:8080).

## Building assets

The editable styles and scripts live in `css/` and `js/`. Rebuild the committed GitHub Pages assets in `dist/` after making changes:

```sh
npm run build
```
